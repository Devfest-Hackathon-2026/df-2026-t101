# ADR-0011：形は、こぶしの外側にかぶせるカバー（方式B）にする。殻は手の3Dメッシュから作る

> **2026-11-10 の注意**：本文は決めたときの記録です。今の動きは、下の「2026-11-10 追記」と [docs/README.md の「11/10 時点の現状」](../README.md#1110-時点の現状先に読む) を見てください。

> **このドキュメントで決めたこと**
> 1. 道具は「手で握る握り」ではなく、こぶしの外側（手の甲・指の背・関節）に手の甲側からかぶせるカバーにし、市販の面ファスナーのベルトで手のひら側を通して留める。指が握った形で固まっている人を主な対象にし、少し曲がっている人にも使える形にする。
> 2. カバー本体（殻）は、手の3Dメッシュ（[ADR-0010](0010-hand-mesh-fusion.md)）の面から、すき間 c と、すき間＋厚み c＋t だけ離れた2つの面の間の層にする。手のひら側・手首側・親指のまわりは切り落とし、切り口も含めてふちはすべて丸める。
> 3. 装具にしない：手のひら側は必ず開け、手首は覆わず、握った指を無理に開かせない。この3つは、描いたあとの検査で自動で確かめる。

- 状態：採用（2026-11-07、チームの決定。元はチームのメモ [notes/2026-11-07-cover-shape.md](../notes/2026-11-07-cover-shape.md)。メモでは殻を指のカプセルから作るとしていたが、ADR-0010 の手の3Dメッシュから作ることにした）。2026-11-08：ベルトは1本に固定した（`catalog.json` の `strap_count`）。2026-11-10：実装に合わせて、下の表に追記した
- 日付：2026-11-07
- 関連：[ADR-0010](0010-hand-mesh-fusion.md)（手の3Dメッシュ。決めたこと2「握りからくり抜く」をこのADRで置き換える）、[ADR-0012](0012-c-clip-dovetail.md)（道具の付け方）、[ADR-0013](0013-clip-angle-variants.md)（角度）、[parts-library.md](../parts-library.md)、[generation-pipeline.md](../generation-pipeline.md)、[measurement.md](../measurement.md)

## 背景

### 最初の案（指のくぼみ付きの握り）の問題

- くぼみが穴になっていると、指が伸びない人は指を差し込めない。リウマチで指が腫れると、抜けなくなる危険もある
- 握って持つ前提なので、握る力が弱い人には使えない
- 筆が握りの端から出ていて指先から遠く、細かい線が描きにくい
- 親指の置き場がない
- 大きく重い

### 次の案（手を上から乗せる、上が開いた溝の台）の問題

- 指が握った形で固まっている人は、手を広げて上に乗せられないので使えない（チームの指摘）

## 比べた案（握った形で固まった手への2つの方式）

| 方式 | しくみ | 良い点 | 困る点 | 判断 |
|---|---|---|---|---|
| A. トンネルに差し込む部品 | 握った指と手のひらの間のすき間に、柔らかい部品を手の横から差し込む。形は、指と手のひらに囲まれた空間を埋める形 | 握る力が要らない | すき間の中の形は外から見えず、動画で測りにくい。指の間に物を押し込むので、皮膚への負担が大きい | 今回は作らない（ピッチで将来の改良として話す） |
| **B. こぶしの外側にかぶせるカバー** | こぶしの外形に沿ったカバーを手の甲側からかぶせ、ベルトで留める。道具はカバーに付ける | 手を開かずに着けられる。外から見える面だけで形が決まる | ベルトが要る。殻なので刷るときに内側にサポートが要る | **採用** |

## 決定

方式Bを採用する。

| 項目 | 決めたこと |
|---|---|
| 部品 | カバー本体、ベルト（市販の面ファスナー）、道具の取り付け部品（C字クリップ。[ADR-0012](0012-c-clip-dovetail.md)）、任意でTPUの筒 |
| 殻の内側 | こぶしの外側（指の背と関節の出っ張り）の形に、すき間 c（`HAND_CLEARANCE_MM`。フェルトの厚みを含む）を足した形。左右対称にせず、その人の関節の凹凸がそのまま出る |
| 殻の厚み | t（`cover_thickness_mm`、既定2.5mm、2.0〜3.5mm。仮の値） |
| 切り落とす所 | 手のひら側（PIP関節の中心の高さの平均＋`palm_cut_offset_mm` より手のひら側）、**手のひら・指の腹を向いた面の上**（一番近い手の面の向きが手のひら側から60度以内の所。2026-11-10 追記：実装は65度で捨て、描いたあとの検査 R6c は50度で見る。`api/app/geometry/shell.py` の `PALM_FACE_DEG`。手のひら側の平面の高さは、PIP の高さと「指の付け根の関節の中心から手のひら側へ8mm」の、手の甲側にあるほう）、**指の上**（基節から先。こぶしの山だけ3mm覆う。2026-11-07 に、指を覆わないよう変えた）、手首側（手首から `wrist_cut_mm` より手首側。25mm以上）、親指のまわり（親指を包まない）。平面だけでは、握りこぶしでPIP関節が手のひらの皮膚より手のひら側に来るため、手のひらの上に殻が残る。そのため面の向きと骨でも捨てる（[parts-library.md §4.1](../parts-library.md#41-カバー本体-cover必須)） |
| ふち | 切り口も含めて、すべて丸める（半径 `edge_radius_mm`、1.5mm以上） |
| そのほか | 空気の通る穴を数か所、両側にベルトを通すスリット、人差し指側の上にアリ溝のレール。内側に薄いフェルトかスポンジを貼る |
| ベルト | 両側のスリットに通し、手のひら側を通して留める。片手でも着け外しできるようにする。1本か2本かは未決だったが、2026-11-08 に1本に固定した（2本にするとスリットがカバーのふちやレールにかかって切れるため。ベルトは親指の下をくぐらせて手のひらだけを通す） |

### 殻を手の3Dメッシュから作る

メモでは「指のカプセルを、すき間＋厚みだけ太らせた和集合から、すき間だけ太らせた和集合を引く」としていた。考え方（手の面から一定の距離の層を殻にする）はそのままにして、元の形を手の3Dメッシュに替える。

```
殻の層：c ≤ sdf(p) ≤ c + t      … sdf(p) は手の3Dメッシュからの符号付き距離（手の中が負）
```

- 理由1：関節の出っ張り・指の背の凹凸・手の甲のふくらみが、カプセル（丸い円柱）よりも実際の形に近く出る。「一人ひとりの手に合わせる」という軸がはっきりする
- 理由2：距離場の計算は、ADR-0010 のスパイクで確かめた仕組み（距離場とマーチングキューブ）をそのまま使える。切り落とす面も距離として組み合わせ、なめらかな共通部分を取れば、切り口のふちも同時に丸くなる（[generation-pipeline.md](../generation-pipeline.md)）
- カプセルは、手のひら側・親指を切る位置を決める目安にだけ使う

## 理由（方式Bを選んだ理由）

1. **手を開かずに着けられる**：握った形で固まった人にも、少し曲がっている人にも使える
2. **測りやすい**：外から見える面だけで形が決まるので、動画で採寸しやすい。トンネルの中の形を測るより確実
3. **皮膚への負担が小さい**：指の間に物を押し込まない
4. **装具にならない**：手のひら側を開けておけば、指を固定・矯正するものにならない
5. **一人ひとりに合う**：カバーの内側がその人のこぶしの形そのものになる
6. **デモで伝わる**：メンバーや審査員が手を握るだけで対象のユーザーと同じ状態を作れ、その場で着けてもらえる

## 安全の決まり

| 決まり | 守り方 |
|---|---|
| 握った指を無理に開かせない | カバーは指の外側にかぶせるだけにする |
| 手のひら側は必ず開けておく（装具にしない） | 手のひら側の平面に加えて、手のひら・指の腹を向いた面の上と、指の上（基節から先）も必ず捨てる。描いたあと、そこに材料がないことを自動で確かめる（R6c） |
| 手首を覆わない | 描いたあと、手首から25mm以内に材料がないことを自動で確かめる |
| 角を丸め、肌を守る | ふちはすべて丸める（1.5mm以上）。内側にフェルトかスポンジを貼るよう案内する |
| 痛みや赤みが出たらやめる | アプリのダウンロードの画面と印刷ガイドで案内する |
| 使う前にOTが確かめる | これまでどおり（デモのケースは除く）。可能なら試し刷りの段階で一度見てもらう |

## 11/7のスパイクで確かめたこと

手元のPC（RTX 4070 Ti SUPER のPCのCPU）で、SAM 3D Body で作った手のメッシュ（握りこぶしではなく、指が少し曲がった手）から、殻を作った。

| 項目 | 結果 |
|---|---|
| 殻の層とつなぎ | `c ≤ sdf ≤ c + t`（c=1.5mm、t=2.5mm）に、手のひら側・手首側・人差し指の外側・親指のまわりを、なめらかな共通部分（半径2mm）でつないで切れた。閉じた1つのかたまりになり、切り口のふちも丸くなった |
| 時間 | 手全体の箱（約1,580万点）では75秒。手を手の座標系に回し、箱をカバーの範囲だけにすると約400万点・20秒 |
| 安全の検査 | 手のひら側の面より手のひら側の頂点なし、手首から35mm以上、手の頂点との最小の距離1.44mm（c=1.5mmをぼかした分だけ下回る。要確認：検査のしきい値に、ぼかしの分の余裕を入れる） |
| 分かったこと | 指が伸び気味の手では、手のひら側の平面だけでは指の背が指先まで覆われた。そのため「中節・末節の上を捨てる」決まり（上の表）が要る |

## 引き受けること

| 危険 | 対策 |
|---|---|
| 殻なので、刷るときに内側（こぶしに当たる面）にサポートが要る | 手のひら側の切り口を下にして刷り、内側にサポートを付ける。サポートの跡はフェルトで隠れる。外側はサポートなしで刷れる形にする（クリップは輪の下にサポートが要る。[parts-library.md §4.5](../parts-library.md)） |
| すき間 c とフェルトの厚みが分からない | 11/9の朝の試し刷りで、指の背の一部だけの小さな殻を刷って決める（要確認）。2026-11-10 追記：11/9 は前の版の3Dモデルで刷ったカバーがメンバーのこぶしに合った。今の版では刷っていないので、`HAND_CLEARANCE_MM`（1.5）とフェルト（1.0）は `catalog.json` で「仮」のまま |
| カバーが手の上で回る | ベルトを幅広にするか2本にする。1本か2本かは試し刷りで決める（未決）。2026-11-08 に1本に固定した（幅は20／25／38mmから選べる） |
| 握りこぶしでは指が重なり、MediaPipeの点がずれやすい | 大きさの倍率は手の甲で見える点（手首と指の付け根）から出し、確認の画面で代表の数枚の点を直せるようにする（[measurement.md](../measurement.md)） |
| 殻の計算の時間 | ADR-0010 のくり抜きと同じく10〜20秒の見込み（要確認）。採寸の版と殻の引数が同じなら使い回す |
