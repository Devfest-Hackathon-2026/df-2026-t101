# ADR-0005：道具を挟む部分はねじ締め式（コレット＋ナット）にし、デモは「筆の握り」で見せる

> **このドキュメントで決めたこと**
> 1. 握りの先に、割りの入った筒（コレット）とねじを付け、ナットを締めると道具の柄を挟んで固定する形にする。これで1つの握りで、筆・ペン・スプーンの柄など、太さの違う道具に対応できる。
> 2. デモの主役は「筆の握り」。同じ握りにペンとスプーンを付け替えて見せる。
> 3. ねじとコレットは刷れるかどうかの危険が一番大きいので、11/9の朝いちばんの試し刷りに入れる（プリンタは11/9・11/10だけ使える）。

- 状態：置き換え済み（2026-11-07、[ADR-0012](0012-c-clip-dovetail.md)。形をこぶしにかぶせるカバーに変え（[ADR-0011](0011-dorsal-cover.md)）、道具はC字クリップとアリ溝で付けることにした。ナットを指先で回す操作が、指が握った形で固まった人やつまむ力が弱い人には難しいため）
- 日付：2026-11-07
- 関連：[parts-library.md](../parts-library.md)、[ADR-0001](0001-gemini-output-json-params.md)
- 提案：チームメンバー（「先をねじ締め式にすると、接続部品の太さを気にせず、筆やペンやスプーンなどにも対応できる」）

## 背景

- デモで作る道具を1種類に絞るかを決める必要があった
- 道具の柄の太さは、同じ筆でも数mm違う。柄に合わせて穴の径をぴったり決める方法では、道具を替えるたびに刷り直すことになる
- 本人がやりたいこと（趣味や仕事）のための道具は、市販されていないことが多い

## 比べた案

| 案 | 中身 | 良い点 | 困る点 |
|---|---|---|---|
| A. 道具ごとに穴を合わせる | 柄の太さに合わせた穴を開ける | 形が単純で、刷るのが簡単 | 太さが少し違うと入らないか、抜ける。道具を替えるたびに刷り直す |
| B. ねじ締め式（コレット＋ナット） | 割りの入った筒をナットの円すいで締める。すべて刷って作る | 1つで約3mmの太さの違いを吸収できる（円すいの長さ9mm・傾き10度からの計算で上限約3.2mm。実際の値は試し刷りで確かめる）。道具を付け替えられる。金具が要らない | ねじが刷れるか、締める力が足りるかが不安。部品が2つになる |
| C. 横からねじで押さえる | 金属のねじとナットで柄を横から押さえる | よく締まる | 金具が要る。ねじの頭が手に当たる |
| D. 面ファスナーのベルト | ベルトで柄を巻く | 何でも付く | 見た目が「いかにも医療用」になりやすい。固定が緩みやすい |

## 決定

Bを採用する。

- コレットは握りの上端と一体で刷る。ナットは別に刷る
- ねじはBOSL2の台形ねじ（ピッチ3mm）を使う。すき間（`$slop`）は11/9の朝に3通り刷り比べて決める
- ナットは「羽根付き」と「ぎざぎざ」の2種類にする。つまむ力が弱い人には羽根付きを選ぶ（Geminiが聞き取りの結果から選ぶ）
- コレットの穴の径は、聞き取りで聞いた柄の太さ＋0.6mmにし、細い分はナットで締めて吸収する

## 理由

1. **やりたいことの幅が広がる**：1つの握りを、筆・ペン・スプーンなど、本人がやりたいことの道具に付け替えられる。「売っていない道具がない」という課題に、部品の数を増やさずに答えられる
2. **採寸の価値が生きる**：本人の手に合わせて作るのは握りの部分で、道具の側は付け替える。手に合わせた部分を、何度も使い回せる
3. **見た目**：金具やベルトを使わず、色を選べる1つの形にまとまるので、「いかにも医療用」に見えにくい
4. **ピッチ**：同じ握りに道具を付け替えて見せると、説明しなくても伝わる

## 引き受けること（危険と対策）

| 危険 | 対策 |
|---|---|
| ねじがつぶれる、きつすぎる、緩すぎる | 11/9の朝いちばんに `thread_test` を刷る。ピッチは粗め（3mm）にし、立てて刷る。11/7・11/8にスライサーのプレビューで、ねじ山の形が崩れないかを確かめる |
| 締める力が足りず、筆が抜ける | コレットの割り片の厚さ（2.0mm）と割りの数（4）を、試し刷りで見直す。印刷ガイドに「強く引いて抜けないか確かめる」と書く |
| PLAが時間とともに緩む（クリープ） | 使う前にナットを締め直すよう、印刷ガイドに書く |
| スプーンの柄は平たく、丸い筒で挟みにくい | スプーンはデモの付け替え用にとどめる。平たい柄がしっかり挟めるかは要検証 |
| スプーンは口に入る | 刷った部品は口に入れない。ナットの先から柄が十分に出るよう案内する（[parts-library.md §8](../parts-library.md#8-安全のための作り込み)） |

## 見直す条件

- 11/9の朝の試し刷りで、どのすき間でもねじがうまく回らない場合は、11/9の昼に、筆1本の太さに合わせた案A（穴をぴったりにする）に切り替える。案Aの形は、11/8までに `main.scad` の引数1つで切り替えられるよう用意しておく。11/9の午後に案Aの握りを刷り、11/10の朝の最終版も案Aにする。ペンやスプーンへの付け替えは、ピッチで「次の改良」として話す
