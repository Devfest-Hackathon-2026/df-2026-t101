# ADR-0012：道具は、太さぴったりのC字クリップで挟み、カバーのアリ溝のレールに差し込む（ねじは使わない）

> **2026-11-10 の注意**：本文は決めたときの記録です。今の動きは、下の「2026-11-10 追記」と [docs/README.md の「11/10 時点の現状」](../README.md#1110-時点の現状先に読む) を見てください。

> **このドキュメントで決めたこと**
> 1. 道具（筆など）は、聞き取りで聞いた道具の太さに合わせて生成するC字クリップで挟む。押し込むだけで固定し、引き抜くだけで外れる。ねじで締める方式（[ADR-0005](0005-screw-collet-tool-holder.md)）はやめる。
> 2. クリップはカバー（[ADR-0011](0011-dorsal-cover.md)）とは別の部品にし、カバーの人差し指側の上にあるアリ溝のレールに横から滑り込ませる。最後に小さな出っ張りで「カチッ」と止まる。道具ごとのクリップを差し替えるだけで使い分けられる。
> 3. 硬さの対策は、形（薄い壁・長めの腕・根元の切り欠き・斜めの入口）と、材料（できればPETG、確実なのはPLAの受け具＋TPUの筒）で行う。しめしろ・アリ溝のすき間・壁の厚さは、11/9の朝の試し刷りで決める。（2026-11-10 追記：根元の切り欠きは 2026-11-08 にやめた。応力が集まり、見積もりで 27→37MPa と PLA の積層の境目の強さを超えるため。TPUの筒はMVPでは使わない（`tpu_sleeve` は false に固定）。11/9 は前の版の3Dモデルで刷ったカバーがメンバーのこぶしに合ったが、今の版のクリップとアリ溝は刷っていないので、しめしろ0.3mm・すき間0.25mm・壁2.0mmは `catalog.json` で「仮」のまま）
> 4. **クリップは生成のたびに描かず、先に作っておいた固定STLから選んで持ってくる**（2026-11-08 追記）。道具の太さ 4〜16mm を 0.25mm 刻み、角度 60／70／80度の組み合わせ（147個。角度は2026-11-08 に 0／20／40 から変えた。[ADR-0013](0013-clip-angle-variants.md) の 4.）を、生成APIのコンテナを作るときに OpenSCAD で描いて同梱する（`scad/library/c_clip/`、`api/app/geometry/cliplib.py`）。壁の厚さ・開きの幅・輪の高さ・内側の溝は `catalog.json` の既定値に固定し、AIは角度と数だけを決める。聞き取りの太さは 0.25mm 刻みに丸める（しめしろの誤差は ±0.125mm）。刻みの外（4mm 未満・16mm 超）や TPU の筒は、従来どおりその場で描く。

## 背景

- 形をこぶしにかぶせるカバーに変えた（ADR-0011）ので、道具をカバーに付ける方法を決め直す必要があった
- 前の方式（ねじ締めのコレット＋ナット、ADR-0005）は、ナットを指先で回す必要がある。指が握った形で固まっている人や、つまむ力が弱い人には、この操作が難しい
- 対象のユーザーは自分で着け外しできないことも多く、家族や介護する人が片手で楽に扱えることも要る

## 比べた案

| 方法 | 着け外し | 良い点 | 困る点 | 判断 |
|---|---|---|---|---|
| **C字クリップ** | 押し込む・引き抜くだけ | 操作がいちばん簡単。部品が1つ | 挟める太さの幅が狭い | **採用**。道具ごとに専用のクリップを刷ることで解決する |
| カムレバー | レバーを倒す・起こす | 指先を使わずに操作でき、太さの幅も広い | 部品が増える | 将来の改良 |
| ねじで締める（ADR-0005） | 指先で回す | 1つで約3mmの太さの違いを吸収できる | 対象のユーザーには回す操作が難しい。ねじが刷れるかの危険も大きい | 不採用 |
| ベルト・ゴム | 巻く・ほどく | 何でも付く | 筆先がぶれやすい | 不採用 |

## 決定

### C字クリップ

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 内径 | 道具の太さ − しめしろ（`CLIP_INTERFERENCE_MM`、既定0.3mm。0.2〜0.4mmを試し刷りで比べる） | 少し小さくして、押し込んだときに締まるようにする。アプリは最初に道具の太さを聞くので、手だけでなく道具にも合わせられる |
| 開きの幅 | 道具の太さの7〜8割（`opening_ratio`、既定0.75） | 開きが道具の太さより狭いので、押し込むと腕がしなって入り、入ったあとは抜けない |
| 入口 | 斜めに削る | 押し込む力を減らす |
| 内側 | 細い溝を付ける（`grip_ribs`） | 滑りにくくする |
| 先が細い道具 | 太さがほぼ一定の位置を挟むか、クリップを2か所にする（`count` 1〜2） | 筆の柄は先に向かって細くなるため |
| 付ける位置 | 人差し指の側から、筆先が人差し指の指先の近くに来る位置 | 細かい線を描きやすくする（最初の握りの案の問題の1つ） |
| 刷る向き | 舌（アリ溝の凸）の底を机に置く向き。輪の下にサポートが要る（2026-11-08 に輪を横へ張り出す形にしてから。それまでは「輪が机と平行」） | アリ溝の面がきれいに出て、レールに滑らかに差し込める |

### アリ溝のレール（カバー側）とクリップの凸

- カバー側にレール（溝）、クリップ側に凸を付け、横から滑り込ませる（実装：溝は手首側の端が開き、指先側の端は閉じている。クリップは手首側の端から溝に沿って差し込み、閉じた端の手前で止まる。`scad/parts/rail.scad`）
- 最後に小さな出っ張り（`detent_mm`、既定0.6mm）で「カチッ」と止まり、勝手に抜けないようにする
- すき間（`DOVETAIL_CLEARANCE_MM`）は既定0.25mm。0.2／0.25／0.3mmを試し刷りで比べる
- レールの幅・深さ・長さ・角度は固定値にし、AIには変えさせない（クリップを差し替えて使うので、どのクリップでも同じレールに入る必要がある）

### 硬さの対策

PLAだけで作ると、押し込むのに力が要る・くり返しで根元が割れる・筆が滑る、という問題が起きやすい。

| 対策 | 中身 |
|---|---|
| 形でしなりを作る | 壁を薄くする、腕を長めにする、根元に小さな切り欠きを入れる、入口を斜めに削る（2026-11-10 追記：切り欠きは 2026-11-08 にやめた。割れやすくなるため。かわりに腕の根元を太くし、ペンは上から軸の向きに差し込む） |
| 材料 | 大学の3DプリンタでPETGが使えれば、クリップはPETGが向いている（PLAより粘りがあり割れにくい）。TPUはクリップだけでは柔らかすぎる。使えるかは要確認 |
| 硬い部品と柔らかい部品の組み合わせ（いちばん確実） | 外側の受け具はPLAで硬く、内側にTPUの薄い筒を入れて、挟むのはTPUに任せる。太さの違う道具には、TPUの筒だけ刷り直せばよい（`tpu_sleeve`。時間があれば。2026-11-10 追記：筒の形は `scad/parts/c_clip.scad` にあるが、MVPでは使わない。`tpu_sleeve` は false に固定） |

## 理由

1. **操作が簡単**：押し込む・引き抜くだけ。指先で回す操作が要らないので、対象のユーザーや、介護する人が片手で扱える
2. **道具にも合わせられる**：道具の太さを聞いて、その太さぴったりのクリップを生成する。挟める幅が狭いという弱点は、道具ごとに刷ることで消える
3. **刷る危険が小さい**：ねじ山（立てると約75度張り出す）のような、刷れるかどうか分からない形がない
4. **差し替えられる**：レールが共通なので、道具や角度（[ADR-0013](0013-clip-angle-variants.md)）を、クリップを替えるだけで変えられる

## 引き受けること

| 危険 | 対策 |
|---|---|
| クリップの根元が、くり返しで割れる | 11/9の朝に、壁の厚さを変えたクリップを2〜3種類刷り、それぞれ数十回着け外しして、押し込みやすさとひびの入り方を比べる |
| しめしろが合わず、緩い・きつい | 11/9の朝に、しめしろ0.2／0.3／0.4mmを刷り比べる |
| アリ溝がきつい・緩い、勝手に抜ける | 11/9の朝に、すき間0.2／0.25／0.3mmを刷り比べ、止めの出っ張りで抜けないかを確かめる |
| PETG・TPUが使えない | PLAで、形でしなりを作る対策だけにする（要確認） |
| 平たい柄（スプーンなど）は丸い穴で挟みにくい | 今回は筆を主にする。ペン・スプーンのクリップは時間があれば作る（2026-11-10 追記：筆・ペン・スプーンのクリップは作った（角度の目安は筆70・ペン60・スプーン60）。平たい柄の取り付け具は作らず、太柄スポンジなどで丸くしてもらう：[ADR-0014](0014-multiple-attachments.md)） |
| 介護する人が扱いにくい | 試し刷りで、家族や介護する人が片手で楽に扱えるかも確かめる |

> 2026-11-10 追記：上の表の 11/9 の朝の試し刷り（壁の厚さ・しめしろ・アリ溝のすき間）は、今の版のクリップとレールでは行っていない（11/9 は前の版の3Dモデルで刷ったカバーがメンバーのこぶしに合った）。値は `catalog.json` で「仮」のまま。

## 見直す条件

- 11/9の朝の試し刷りで、どのしめしろでもクリップがうまく挟めない、または割れる場合は、TPUの筒を使う組み合わせに切り替える。TPUも使えなければ、PLAのクリップの壁を厚くし、内径を道具の太さ＋0.2mmにして、ベルトで補う形を検討する（要確認）
