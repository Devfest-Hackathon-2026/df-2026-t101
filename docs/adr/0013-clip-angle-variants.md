# ADR-0013：道具の角度は、角度違いのクリップを差し替えて変える（回す仕組みは作らない）

> **このドキュメントで決めたこと**
> 1. 道具の角度を変える仕組み（回して止める関節など）は作らない。角度違いのC字クリップを用意し、差し替えて変える。
> 2. 角度は、やりたいことからGeminiが選び、理由を書く。ユーザーはプレビューの画面で角度を選び直せる（クリップだけを描き直す）。
> 3. まず1種類以上を作る。角度違いを何種類用意するかは未決で、時間があれば増やす。
> 4. **角度の意味と選択肢を変えた（2026-11-08）**：クリップは輪をこぶしの親指側の横へ張り出させ、道具をこぶしの横に立てる。角度は「机（手の甲を上にして置いた姿勢）に対する道具の傾き」で、**60／70／80度**から選ぶ（筆70・ペン60）。前の「レールの向きからの傾き 0／20／40度」は、実物の長さのペンで計算すると、どの角度でも穂先が机に届かず（こぶしは机から約90mm、クリップはその上）、40度では指の背に当たったので捨てた。

## 背景

- 筆で絵を描く、字を書く、スプーンで食べるなど、やりたいことによって、道具を手に対してどの角度で持つのがよいかが違う
- 角度を調整する方法を決める必要があった

## 比べた案

| 案 | 中身 | 良い点 | 困る点 | 判断 |
|---|---|---|---|---|
| 回して角度を変える仕組み | クリップの台を回して、好きな角度で止める | 1つの部品でどの角度にもできる | 止めるのに、結局ねじが要る。指先で回す操作は対象のユーザーに難しい（[ADR-0012](0012-c-clip-dovetail.md)）。刷る部品も増える | 作らない |
| **角度違いのクリップの差し替え** | 60度・70度・80度など、角度違いのクリップを刷り、レールに差し替える | ねじが要らない。差し替えるだけ。どのクリップも同じレールに入る | 角度ごとにクリップを刷る | **採用** |

## 決定

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 角度の選択肢 | 60度・70度・80度（`c_clip.angle_deg`。2026-11-08 に 0／20／40 から変えた） | 少ない種類で、書くときの立て具合の幅を覆うため。何種類にするかは未決 |
| 角度の基準 | 机に手の甲を上にして置いた姿勢で、机に対する道具の傾き。90度が垂直。輪はレールの上面の中心から親指側へ20mm・手のひら側へ6mm・指先側へ5mm張り出した所にあり（`scad/parts/c_clip.scad`）、道具はこぶしの親指側の横を通って、人差し指の付け根の横あたりで机に届く（11/8 の計算：こぶしの横を通るので手・カバーに当たらず、クリップから約80mmで机に届く） | 手の甲の上から下へ向けると、必ずこぶし（指の背）を越えなければならず、こぶしの高さ（約90mm）の分だけ先が遠くなる。横に出せば、普通にペンを持ったときの穂先の位置に近くなる |
| 選び方 | Geminiが、やりたいことから選び、理由を書く。例：筆＝70度、ペン＝60度（仮の値。スプーンは未検証で60） | 「決めた理由を説明できるAI」の役割と合わせる |
| 変え方 | プレビューの画面（S7）で、ユーザーが60／70／80度から選び直せる。カバーは描き直さず、クリップだけを差し替える（固定STLのライブラリ。[ADR-0012](0012-c-clip-dovetail.md) の 4.） | 角度はカバーの形に関係しないため。待ち時間を短くする |
| 確かめ方 | 描いたあとの検査 R6h：クリップの位置から道具の軸を引き、手・カバーとのすき間と、机に届く距離を測る（[generation-pipeline.md](../generation-pipeline.md)） | 同じ失敗（当たる・届かない）を繰り返さないため |
| 作る数 | まず1種類以上（選んだ角度）。時間があれば、ほかの角度も一緒に刷れるようにする | 11/9・11/10しか刷れないため |

## 理由

1. **ねじが要らない**：回して止める仕組みは、結局ねじが必要になる。ねじをやめた理由（指先で回す操作が難しい）と矛盾しない
2. **操作が簡単**：クリップを引き抜いて、別の角度のクリップを差し込むだけ
3. **部品が単純**：角度はクリップの形だけで決まり、カバーとレールは共通

## 引き受けること

| 危険 | 対策 |
|---|---|
| 60／70／80度の間の角度が合う人がいる | プレビューで3つを見比べて選んでもらう。細かい角度は将来の改良（クリップの角度を5度刻みで生成するなど） |
| 角度ごとに刷る手間がかかる | クリップは小さいので、1回で数個を並べて刷れる |
| 角度の例（筆＝70度など）が本人に合わない | 例は仮の値。OTの確認と、プレビューでの選び直しで補う（要確認） |
