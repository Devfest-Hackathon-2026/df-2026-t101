design-notes-from-chat.md のあとに、チャットで形状を検討して決めたことのまとめです。このメモの内容は、最初の設計依頼プロンプトと design-notes-from-chat.md より優先します（特に「握りの形」と「部品ライブラリ」）。

## 1. 変更点のまとめ

| 項目 | これまで | このメモでの決定 |
|---|---|---|
| 対象の手 | 指が曲がったまま伸びない人（漠然） | 指が握った形で固まっている人を主な対象にする。少し曲がっている人にも使える形にする |
| 道具の形 | 指のくぼみが付いた「握り」を手で握る | こぶしの外側（指の背と関節）に合わせたカバーを手の甲側からかぶせ、ベルトで固定する |
| 握りの作り方 | 握りの本体から、指のカプセルをくり抜く | 指のカプセルを太らせて**殻（シェル）**を作り、手のひら側を切り落とす |
| 道具の固定 | 筆を挟む部品（ねじ止めの想定） | 道具の太さに合わせたC字クリップを、カバーの**差し込み式の台座（アリ溝）**に付ける。ねじは使わない |
| 角度の調整 | 未定 | 角度違いのクリップを差し替える（回す仕組みは作らない） |

## 2. 形を変えた理由（検討の経緯）

### 2.1 最初の案（指のくぼみ付きの握り）の問題

- くぼみが穴になっていると、指が伸びない人は指を差し込めない。リウマチで指が腫れると抜けなくなる危険もある
- 握って保持する前提なので、握る力が弱い人には使えない
- 筆が握りの端から出ていて、指先から遠く、細かい線が描きにくい
- 親指の置き場がない
- 大きく重い

### 2.2 次の案（手を上から乗せる、上が開いた溝の台）の問題

- 指が握った形で固まっている人は、手を広げて上に乗せることができないので、この形は使えない（チームの指摘）

### 2.3 握った形で固まった手への2つの方式

| 方式 | しくみ | 採用 |
|---|---|---|
| A. トンネルに差し込む部品 | 握った指と手のひらの間のすき間に、柔らかい部品を手の横から差し込む。部品の形は、指と手のひらに囲まれた空間を埋める形 | 今回は作らない（ピッチで将来の改良として語る） |
| B. こぶしの外側にかぶせるカバー | こぶしの外形に沿ったカバーを手の甲側からかぶせ、ベルトで固定。道具はカバーに付ける | 採用 |

Bを採用した理由

- 手を開かずに着けられる。握った形で固まった人にも、少し曲がっている人にも使える
- 外から見える面だけで形が決まるので、動画で採寸しやすい。トンネルの中の形を測るより確実
- 指の間に物を押し込まないので、皮膚への負担が小さい
- 手のひら側を開けておけば、指を固定・矯正する装具にならない
- カバーの内側がその人のこぶしの形そのものになるので、「一人ひとりの手に合わせる」という軸は残る
- デモで、メンバーや審査員が手を握るだけで対象ユーザーと同じ状態を作れ、その場で着けてもらえる

## 3. 形の仕様

### 3.1 部品構成

- カバー本体
- ベルト（市販の面ファスナー）
- 道具の取り付け部品（C字クリップ。道具ごと・角度ごとに用意）
- （任意）TPUの筒（C字クリップの内側に入れる）

### 3.2 カバー本体

- 内側：こぶしの外側（指の背と関節の出っ張り）の形に、すき間を足した形
- 手のひら側は開けておく。上からかぶせるだけで着けられる
- 手首は覆わない（手首の動きを妨げない）
- ふちはすべて丸める
- 空気の通る穴を数か所開ける
- 内側に薄いフェルトかスポンジを貼る（肌の保護と、採寸の誤差の吸収）
- 両側にベルトを通すスリットを開ける
- 人差し指側の上に、道具の取り付け部品を差し込むレール（アリ溝）を付ける
- 形は左右対称にしない。その人の関節の凹凸がそのまま出る形にする

### 3.3 ベルト

- 両側のスリットに面ファスナーのベルトを通し、手のひら側を通して留める
- 片手でも着け外しできるようにする
- カバーが手の上で回ってしまう場合は、ベルトを幅広にするか2本にする

### 3.4 道具の取り付け部品

固定方法の比較（検討結果）

| 方法 | 着け外し | 判断 |
|---|---|---|
| C字クリップ | 押し込む・引き抜くだけ | 採用。挟める太さの幅が狭いのは、道具ごとに専用のクリップを刷ることで解決する |
| カムレバー | レバーを倒す・起こす | 指先を使わずに操作でき、太さの幅も広いが、部品が増える。将来の改良 |
| ねじで締める | 指先で回す | 対象ユーザーには操作が難しいので不採用 |
| ベルト・ゴム | 巻く・ほどく | 筆先がぶれやすいので不採用 |

C字クリップの仕様

- アプリは最初に道具の太さを聞くので、その道具の太さぴったりのクリップを生成する（手だけでなく道具にも合わせる）
- 押し込むだけで固定、引き抜くだけで外れる
- 入口を斜めに削り、押し込む力を減らす
- 内側に細い溝を付けて滑りにくくする
- 筆の柄は先に向かって細くなるので、太さがほぼ一定の位置を挟むか、クリップを2か所にする
- 人差し指の側から、筆先が指先の近くに来る位置に付ける

クリップをカバーに付ける部分

- カバー側にレール、クリップ側に凸を付けたアリ溝で、横から滑り込ませる
- 最後に小さな出っ張りで「カチッ」と止まり、勝手に抜けないようにする
- 道具ごとのクリップを差し替えるだけで使い分けられる

角度

- 回して角度を変える仕組みは作らない（結局ねじが必要になるため）
- 0度・20度・40度など、角度違いのクリップを用意する。やりたいことに合わせて、AIが角度を選ぶ

### 3.5 クリップの硬さへの対策

PLAだけで作ると、押し込むのに力がいる・繰り返しで根元が割れる・筆が滑る、という問題が起きやすい。

- 形でしなりを作る：壁を薄くする、腕を長めにする、根元に小さな切り欠きを入れる、入口を斜めに削る
- 材料：大学の3DプリンタでPETGが使えれば、クリップはPETGが向いている（PLAより粘りがあり割れにくい）。TPUはクリップ単体では柔らかすぎる
- 硬い部品と柔らかい部品の組み合わせ（一番確実）：外側の受け具はPLAで硬く、内側にTPUの薄い筒を入れて、挟むのはTPUに任せる。太さの違う道具には、TPUの筒だけ刷り直せばよい

## 4. OpenSCADでの作り方

design-notes-from-chat.md の「4. 手の3Dモデル」で作る、指のカプセルの手のモデル（握った状態）をそのまま使い回す。

1. 動画から、握った指のカプセルのモデルを作る（長さ・角度・太さ）
2. 各カプセルを「すき間＋カバーの厚み」だけ太らせた和集合から、「すき間」だけ太らせた和集合を引く。これでこぶしに沿った殻ができる（重い minkowski() を使わずに済む）
3. 手のひら側を平面で切り落とす（difference() で直方体を引く）
4. 手首側を切り落とす
5. ふちを丸める
6. 空気穴、ベルトのスリット、アリ溝のレールを付ける

→ design-notes-from-chat.md の「4.2 処理の流れ」の手順8（握りの本体からカプセルをくり抜く）は、この手順2〜6に置き換える。

部品ライブラリ（docs/parts-library.md）に入れるもの

| 部品 | 主な寸法（パラメータ） |
|---|---|
| カバー本体（殻） | すき間、カバーの厚み、手のひら側を切る位置、手首側を切る位置、ふちの丸み |
| 空気穴 | 穴の直径、個数、位置 |
| ベルトのスリット | ベルトの幅、厚み、位置 |
| アリ溝のレール（カバー側） | 幅、深さ、長さ、止めの出っ張りの位置 |
| C字クリップ | 道具の太さ（内径）、壁の厚さ、開きの幅、腕の長さ、角度、内側の溝の有無、TPUの筒を入れるかどうか |
| TPUの筒（任意） | 内径、外径、長さ |

## 5. 試し刷りで決める値

以下は一般的な目安で、プリンタや材料で変わる。11/8の試し刷りで、クリップとアリ溝だけを小さく刷って先に合わせる。

| 値 | 初期値の目安 |
|---|---|
| C字クリップの開きの幅 | 道具の太さの7〜8割 |
| C字クリップの内径 | 道具の太さより0.2〜0.4mm小さく |
| アリ溝のすき間 | 0.2〜0.3mm |
| カバーとこぶしのすき間 | 試し刷りで決める（フェルトの厚みも考える） |

- C字クリップは、輪が机と平行になる向きで刷る（縦に刷ると積層の境目から割れやすい）
- 壁の厚さを変えたクリップを2〜3種類刷り、それぞれ数十回着け外しして、押し込みやすさとひびの入り方を比べる
- 対象ユーザーは自分で着け外しできないことも多いので、家族や介護する人が片手で楽に扱えるかも確かめる

## 7. 安全上の決まり

- 握った指を無理に開かせない。カバーは指の外側にかぶせるだけにする
- 手のひら側は必ず開けておく。指や関節を固定・矯正するもの（装具）にしない
- 手首を覆わない
- 指や手に当たる部分の角はすべて丸め、内側にフェルトかスポンジを貼る
- 痛みや赤みが出たら使用をやめるよう、アプリで案内する
- 使う前に作業療法士が確認する（可能なら試し刷りの段階で一度見てもらう）
